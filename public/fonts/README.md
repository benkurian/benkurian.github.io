# Fonts

## Helvetica Neue (active)

Self-hosted **Helvetica Neue** in Light, Regular, Medium, and Bold — the same cuts used on [Bureau Tonalli](https://www.bureautonalli.com).

Files live in `helvetica-neue/*.woff2`.

## Nimbus Sans L (legacy)

URW **Nimbus Sans** OTF files remain in this folder as a Helvetica-compatible fallback but are no longer referenced in the site stylesheet.
